# VisionMate Research Architecture

This module group introduces the publication-oriented pipeline for VisionMate:

- MPAM: Memory-Augmented Perception Module
- APE: Adaptive Perception Engine
- CAE: Context Aggregation Engine
- HSRM: Hierarchical Scene Representation Module
- MDL: Memory-Driven Language Module
- LCRE: Language-Conditioned Reasoning Engine
- Evaluation: metrics and experiment tracking

The implementation is intentionally modular and backward compatible with the existing webcam and detection flow.
